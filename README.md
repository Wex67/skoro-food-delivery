# 🍔 СКОРО — сервис доставки еды

**СКОРО** — демонстрационный веб-сервис доставки еды, позволяющий пользователям выбирать рестораны, просматривать меню и добавлять блюда в корзину.

Проект разработан с использованием HTML, CSS и JavaScript без сторонних frontend-фреймворков.

## 🚀 Возможности

- 🏙️ **Выбор города** — возможность выбрать город доставки.
- 🍕 **Каталог ресторанов** — 6 ресторанов с разными кухнями, рейтингами и отзывами.
- 🔎 **Поиск** — быстрый поиск ресторанов.
- 📋 **Меню ресторанов** — отдельная страница с блюдами, описаниями и ценами.
- 🛒 **Корзина** — добавление и удаление товаров, изменение количества и автоматический подсчёт стоимости.
- ➕ **Счётчик товаров** — изменение количества блюд прямо на карточках.
- 🌙 **Тёмная тема** — переключение между светлым и тёмным оформлением.
- 💾 **Сохранение данных** — корзина и выбранная тема сохраняются с помощью `localStorage`.
- 📱 **Адаптивный дизайн** — корректное отображение на компьютерах, планшетах и смартфонах.
- ✨ **Анимации** — плавные переходы, интерактивные карточки и движущаяся рекламная строка.

## 💻 Запуск проекта

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Wex67/skoro-food-delivery.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd skoro-food-delivery
   ```

3. Откройте файл `index.html` в браузере. Файл `style.css` должен находиться рядом с ним.

Для удобной разработки рекомендуется использовать расширение **Live Server** в Visual Studio Code.

Для открытия сайта дополнительные зависимости не требуются. Для автоматических скриншотов GitHub Actions устанавливает Playwright и Chromium.

## 📷 Автоматические скриншоты

При каждом обновлении ветки `main` GitHub Actions создаёт скриншоты всей страницы для телефона (390 px), планшета (768 px) и компьютера (1440 px). Скриншоты создаются по файлам конкретного коммита, поэтому их можно использовать для сравнения изменений.

Чтобы скачать изображения:

1. Откройте вкладку **Actions** в репозитории.
2. Выберите workflow **«Скриншоты сайта»**, затем нужный запуск с зелёной галочкой.
3. Внизу страницы запуска, в разделе **Artifacts**, скачайте архив **skoro-screenshots**.

Скриншоты хранятся 30 дней. Создать их повторно можно через **Run workflow** на странице этого workflow. Публикация сайта продолжает выполняться отдельным процессом **Deploy static site**.

## 📌 Статус проекта

**Демонстрационный проект.**

Сайт предназначен для демонстрации frontend-разработки и пользовательского интерфейса сервиса доставки еды.

Рестораны, рейтинги, отзывы и блюда являются демонстрационными данными. Реальное оформление заказов, онлайн-оплата и интеграция со службами доставки не реализованы.
